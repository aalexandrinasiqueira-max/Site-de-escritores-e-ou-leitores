# Site-de-escritores-e-ou-leitores
Um site onde escritores podem escrever e publicar suas histórias, enquanto os leitores podem ler essas publicações.
*Aqui, os escritores podem publicar suas histórias, e os leitores acompanham as escritas de seus autores favoritos. Além de poderem conversar entre si: Escritores podem trocar ideias com outros escritores; os leitores podem conversar entre si, conversando sobre seus escritores e suas obras favoritas; além dos escritores e leitores também poderem conversar, para o leitor tirar alguma dúvida sobre a historia, elogiar a obra, dar suas opiniões para o escritor e, o escritor, por sua vez, responder os seus leitores.
*Linguagem usada: HTML, CSS e JavaScript.
*Plataforma utilizada para escrever os códigos: VS Code.
*Projeto em **andamento/parado**.
